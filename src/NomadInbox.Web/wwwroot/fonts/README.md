# Fonts

Self-hosted so the app looks the same with no internet. Latin-subset WOFF2 files from the Fontsource npm packages; each folder holds the font's license (SIL Open Font License 1.1).

| Folder | Package | Used by |
|---|---|---|
| barlow | @fontsource/barlow 5.3.0 (400, 600) | Basecamp body |
| barlow-condensed | @fontsource/barlow-condensed 5.3.0 (600, 700) | Basecamp headings, nav |
| bitter | @fontsource-variable/bitter 5.3.0 | Ember headings |
| source-sans-3 | @fontsource-variable/source-sans-3 5.3.1 | Ember body |
| ibm-plex-sans | @fontsource/ibm-plex-sans 5.3.0 (400, 600) | Signal body |
| ibm-plex-mono | @fontsource/ibm-plex-mono 5.3.0 (500) | Signal headings, nav, mono |
